## Problemas y cómo se resolvieron

- El nombre de migración del plan ya lo usaba `groups_and_enrollment`: se cambió a `20261119120000`.
- `providerSettingOf()` quitaba sin avisar los respaldos de un host no permitido. La función lo lee aceptando cualquier host y comprueba el host de cada modelo (D-076).
- El `upsert` no aceptaba `Json`, que puede ser `null`, como valor: se pasó como `NonNullable<Json>`.
- Quedaba una rama sin cubrir, la prueba de un ajuste sin respaldos en el simulado: se añadió ese caso.

## Decisiones

- [D-076](../DECISIONES.md): partir el paso en dos, un resultado por modelo también con un host no permitido, límite diario, cómo se distingue el `timeout` y los formatos de los presets.
