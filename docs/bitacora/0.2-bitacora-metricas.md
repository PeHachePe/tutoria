## Problemas y cómo se resolvieron

1. **Respuestas repetidas en los registros de sesión.** Contarlas tal cual casi triplicaba los tokens. Se cuenta cada respuesta una vez por `message.id` y `requestId`.
2. **Rutas de Windows en la entrada de los hooks** (absolutas y con `\`). Se guardan relativas al proyecto y con `/`. Las de fuera del proyecto se guardan relativas a la carpeta del usuario (`~/…`), para no registrar su nombre.
3. **Que el hook nunca moleste.** Ante cualquier error (entrada no válida, archivo bloqueado) termina sin escribir y con código 0, así que no interrumpe la sesión.
4. **Los hooks entraron en vigor sin reiniciar.** Claude Code cargó `.claude/settings.json` en cuanto se creó, y esta misma sesión ya registró sus comandos y ediciones. El inicio de sesión y las peticiones se verán en la siguiente.
