## Problemas y cómo se resolvieron

- **Un campo deshabilitado no se valida** en Signal Forms: el test del secreto del principal no daba error con un preset. Es lo esperado (el preset no se escribe); el test pasa a «Otro».
- **Los datos simulados quedaban guardados entre tests** (el proveedor guardado en un test aparecía en el siguiente): `localStorage.clear()` tras cada test, como `users-page.spec.ts`.
- **En el móvil,** la pista del secreto (dos líneas) se montaba sobre el campo siguiente y cada respaldo ocupaba media pantalla: pista con `subscriptSizing="dynamic"` y modelo y segundos en una fila.
- **Cobertura:** las ramas sin usar se cubrieron con tests (cancelar el diálogo, guardar sin probar, una asignatura escrita en inglés) y con un esqueleto que solo sale en la primera carga, como en usuarios.
