## Problemas y cómo se resolvieron

1. **APIs de JavaScript más nuevas que el target.** El proyecto compila para ES2022, el valor de `ng new`, y la primera versión de `isStuck()` usaba `findLast`, `toReversed` y `Set.prototype.intersection`. En lugar de subir el target, se reescribió con `at`, `filter` y un bucle: `Set.prototype.intersection` todavía no es «ampliamente disponible» en los navegadores.
2. **`TestBed.inject` con una lista de clases abstractas.** TypeScript infería la unión de las nueve clases y no la aceptaba como token. Se tipó la lista como `AbstractType<unknown>[]`.
